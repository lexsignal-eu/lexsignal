Human + Agent Interface

Regulatory signals in machine-readable form.

Public read-only snapshots of official-source regulatory publications, designed for tools, researchers and AI agents that need structured fields rather than HTML scraping.

Research preview — not editorially verified. Every extracted item is marked unreviewed. Automated priority labels are only keyword screening. Check the original regulator publication before drawing conclusions, and do not treat these feeds as legal advice.

Example use

Read once and filter locally; this is currently a static data feed without server-side search parameters.

curl -fsSL https://lexsignal-eu.github.io/lexsignal/api/v1/updates.json | jq '.items[] | select(.authority == "ESMA") | {title, publishedOn, sourceUrl, reviewStatus}'

How agents should use LexSignal

  1. Read the source status and record the snapshot timestamp.
  2. Filter JSON entries for the needed authority, topic or sector.
  3. Open the linked primary-source publication to confirm both facts and procedural status.
  4. Carry over the explicit unreviewed status, and distinguish regulatory changes from consultations, decisions, firm warnings and press releases.

Limitations: No authentication or paid API, no streaming, no live natural-language endpoint, no operational MCP server, no guarantee of crawler discovery, no uptime or latency SLA. Cross-origin browser JavaScript may require a compatible host because custom CORS headers are not configured on GitHub Pages. Server-side HTTP GET is supported.
