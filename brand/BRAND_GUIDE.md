# LexSignal — Brand Identity v1.0

## Core symbol
A restrained sphere of foresight, built from transparent circular signal bands. The visual identity is original concept art inspired by intelligence, reach, continuity and signal.

### Golden-ratio construction
- φ = (1+√5)/2 ≈ 1.61803398875.
- Sphere centre (256, 256), radius **R = 220** in a 512×512 viewBox.
- Four exact radii **R/φ²**, **R/φ**, **R**, **Rφ**; each is φ times the preceding radius.
- Arc centres **(155+rᵢ, 500)**.
- Arc thickness **4.7 φⁱ**, increasing by φ successively.
- True circle arc commands (SVG `A`) with transparent annulus cutouts; no raster tracing.
- The path is clipped to the sphere, so the negative space adapts to any background.
- Small-size legibility checked in 32px PNG local export.
